## 2. Сноски (Footnotes)

Markdown чрезвычайно полезен в коммерческой и академической разработке[^markdown]. Данный инструмент позволяет лаконично дополнять текст важными примечаниями, не перегружая основной абзац.

---

## 3. Alert-блок GitHub

> [!TIP]
> Для экранирования специальных символов в Markdown используйте обратный слэш `\`. Например, чтобы написать слово \*курсив\* без применения форматирования, напишите его как `\*курсив\*`.

---

## 4. Escape-символы (Экранирование)

* Заголовок без форматирования: \# Это не заголовок
* Звёздочка как текст: \*просто звёздочка\*
* Нижнее подчёркивание без курсива: \_обычный текст\_

---

## 5. Встроенный HTML в Markdown

<p style="background-color: #f8f9fa; padding: 15px; border-radius: 5px;">
Этот параграф оформлен с помощью тега <strong>&lt;p&gt;</strong> со встроенными стилями прямо внутри Markdown-документа.
</p>

## Сноски
[^markdown]: Синтаксис Markdown поддерживается на GitHub, GitLab, в большинстве современных редакторов кода и систем документирования.
